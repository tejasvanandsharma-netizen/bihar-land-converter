# 🏡 Bihar Land Converter

A fast, reliable, and free web-based tool to convert land measurement units commonly used in Bihar, India. 

**Live Website:** [https://bihar-land-converter.netlify.app/](https://bihar-land-converter.netlify.app/)

## 📖 About The Project
In Bihar, land is measured using traditional units like Kattha, Dhur, Bigha, and Decimal. Because the value of a Kattha changes from district to district (and sometimes village to village), manual calculations often lead to confusion and errors. 

This project solves that problem by providing a clean, mobile-friendly calculator with district-specific presets.

## ✨ Features
- **District Presets:** Accurate Kattha values for Patna, Muzaffarpur, Vaishali, and West Champaran.
- **Custom Area Input:** Users can enter their own local Mauza/Village name and custom Kattha value.
- **Multiple Conversions:** Convert between Kattha, Dhur, Bigha, Decimal, Acre, Square Feet, and Square Meters.
- **Bilingual (Hindi/English):** Full UI support for both languages.
- **Dark/Light Mode:** Saves user preference in `localStorage`.
- **SEO & Mobile Optimized:** Fully responsive design with SEO-friendly blog articles.
- **Zero Backend:** All calculations happen locally in the user's browser. No data is sent to a server.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (No external libraries/frameworks).
- **Hosting:** Netlify (Auto-deployed from GitHub).
- **Monetization:** Adsterra (Popunder & Banner ads).
- **SEO:** Google Search Console & XML Sitemaps.

## 🚀 How to Run Locally
Since this is a static website, no build tools or node modules are required.
1. Clone this repository.
2. Open `index.html` in any web browser. That's it!
